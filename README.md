//CONDITONALS//

_Definition_

-creating conditions to allow access to certain information
-Utilizes "if", "else if", and "else", combined with "&&" and "||" to meet a ternary (one-line shortcut)
-Examples shown in index.js

_Comparison Operators_

-mentioned before. ===, ==, !=, !==, >=, <=, etc...
-REMEMBER!: an ! can be attached to a variable as well. It just signals for the OPPOSITE of the variable of operator.

_Logical Operators_

-&&: checks if both the left and right side of the comparison is true
-||: checks to see if either the left or right side of the comparison is true

_Truthy & Falsy Values_

-truthy values are responses that give back a variable of any data type in an if statement
-falsy values return "undefined, empty string, null, NaN (not a number), 0, or false
-the truthy value should return in the if statement
-falsy values can come through in the else

_Ternary Operators_

-a shortcut utilizing ? for true and : for false
-examples in index.js
